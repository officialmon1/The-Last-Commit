The Amber Ruins - Ruined Pillar texture files

This archive contains five 2048 x 2048 PNG maps extracted unchanged from
The_Amber_Ruins_Ruined_Pillar.fbx:

Albedo, Normal, Roughness, Ambient Occlusion (AO), and Opacity.

The Stone and Vegetation material definitions are embedded in the FBX.
This texture archive does not contain Unity .mat files.

To create editable Unity material files:
1. Import the FBX into your Unity Assets folder.
2. Select the FBX in the Project window.
3. In the Inspector, open Materials.
4. Click Extract Materials and choose a folder in Assets.
5. Use Extract Textures on the same tab to extract the embedded images,
   or unzip the PNGs in this archive into your project's Assets folder.

If import is disabled, select an available material import mode instead of
None. Material/shader configuration depends on your render pipeline.

Unity documentation:
https://docs.unity.com/en-us/engine/6000.7/manual/assets-and-media/asset-types/models/importing/fbximporter-materials
